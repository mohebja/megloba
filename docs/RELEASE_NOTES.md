# Global SMS - Release Notes

## Version 1.0.0 (Initial Production Release)

### Core Features
- **Default SMS Handler Integration:** Full Android SMS/MMS receiving and sending architecture.
- **Persian Language & RTL Support:** Native Persian text rendering, Jalali (Shamsi) calendar conversion, Persian digit display, and symmetric RTL layout.
- **Long SMS & Unicode Segmentation:** Real-time SMS character counter for Unicode (70 chars) and GSM 7-bit (160 chars).
- **Dual SIM Management:** Multi-SIM support with per-message SIM selector.
- **Bank Message Engine:** Automatic categorization for Iranian and international banks with one-tap OTP code copying.
- **Phishing & Spam Security Scanner:** Real-time threat detection for suspicious URLs, fraud keywords, and advertisement senders.
- **Private Vault:** Encrypted hidden storage protected by PIN and Biometrics (Fingerprint/Face).
- **Scheduled SMS:** Future message dispatching powered by Android `WorkManager`.
- **Encrypted Backup & Restore:** Password-protected AES-256 backup export and import.
- **Voice Assistant (TTS):** Integrated Text-To-Speech reader supporting Persian and English.
- **Material 3 Themes:** Light, Dark, and AMOLED True Dark Mode.
