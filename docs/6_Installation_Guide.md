# 6. Installation & Deployment Guide — Global SMS

---

## 1. Prerequisites
- Android device running Android 7.0 (API level 24) or higher.
- Cellular SIM card installed (Dual SIM supported).

---

## 2. Installation Steps (APK / AAB)

1. **Direct APK Installation:**
   - Transfer `app-release.apk` to device.
   - Tap file in file manager and enable 'Install from unknown sources' if prompted.
   - Tap 'Install'.

2. **Google Play Store Installation (AAB):**
   - Upload `app-release.aab` to Google Play Console.
   - Complete store listing and default SMS handler disclosure declaration.
   - Publish to Production or Internal Testing track.
