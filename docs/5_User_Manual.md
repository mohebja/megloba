# 5. User Manual — Global SMS

---

## 1. Getting Started
1. **First Launch:** Grant required SMS and Notification permissions when prompted.
2. **Default SMS App:** Tap 'Set as Default SMS App' when system dialog appears.

---

## 2. Main Features & Navigation

- **Switching UI Modes:** Go to Settings -> Appearance -> UI Mode. Choose between **Classic SMS**, **Smart AI**, or **Enterprise CRM**.
- **Sending SMS:** Tap the Compose FAB button, pick a contact or type a phone number, type your message, and select SIM 1 or SIM 2 before sending.
- **Private Vault:** Swipe right on a sensitive conversation and select 'Move to Vault'. Access your vault from the menu using your PIN or Biometric authentication.
- **Theme & Font Customization:** Choose from 30 color palettes and Persian fonts (Vazirmatn, Samim, Yekan) in Appearance Settings.
- **Encrypted Backup:** Go to Settings -> Backup & Restore -> Export Backup. Set a password to generate an AES-256 encrypted file.
