# Sprint 8 — Google Play Store Listing & Marketing Assets Report

**Project:** Global SMS (`com.global.sms`)  

---

## 1. Store Description (Persian - فارسی)

**عنوان:** پیام‌رسان هوشمند و امن پیامک گلوبال  
**توضیح کوتاه:** پیام‌رسان پیش‌فرض هوشمند، هوش مصنوعی آفلاین، گاوصندوق خصوصی و مدیریت پیامک‌های بانکی.  

**توضیحات کامل:**  
پیام‌رسان گلوبال اس‌ام‌اس (Global SMS) یک اپلیکیشن پیام‌رسان پیشرفته، امن و فوق‌العاده سریع است که با بهره‌گیری از هوش مصنوعی ۱۰۰٪ محلی (آفلاین)، تجربه‌ای کاملاً متفاوت از مدیریت پیامک‌ها را برای شما به ارمغان می‌آورد.

**ویژگی‌های کلیدی:**
- **هوش مصنوعی آفلاین:** خلاصه خودکار گفتگوها، پاسخ هوشمند، و استخراج کارهای روزانه بدون نیاز به اینترنت.
- **گاوصندوق خصوصی (Private Vault):** قفل بیومتریک و رمزنگاری پیشرفته برای پیام‌های حساس.
- **شناسایی پیامک‌های بانکی:** دسته‌بندی خودکار تراکنش‌ها و محاسبه هزینه‌های ماهانه.
- **پشتیبانی کامل از دو سیم‌کارت:** مدیریت آسان و سریع خطوط ارتباطی.
- **سیستم مدیریت مشتریان (Enterprise CRM):** مناسب برای کسب‌وکارها و ارسال پیامک‌های گروهی.

## 2. Store Description (English)

**Title:** Global SMS: Secure AI Messenger  
**Short Description:** Default SMS app with offline AI, private vault, bank transaction scanner, and dual SIM support.  

**Full Description:**  
Global SMS is an enterprise-grade, secure, and lightning-fast default SMS application powered by a 100% on-device local AI engine. Enjoy automated message categorization, private vault encryption, and bank transaction tracking without ever sending your data to the cloud.
