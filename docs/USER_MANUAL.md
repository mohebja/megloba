# Global SMS - User Manual

## Getting Started
1. **Set as Default SMS App:** Upon initial launch, approve Default SMS Handler permissions to allow Global SMS to manage incoming and outgoing SMS/MMS messages.
2. **Navigating Folders:** Use the category filter chips at the top of the main screen to filter by **Personal**, **Bank**, and **Work**.
3. **Private Vault:** Tap the Lock icon in the top app bar to enter your encrypted vault. Enter default PIN `1234` or use Fingerprint authentication.
4. **Copying OTP Codes:** When a bank message with a verification code arrives, tap the **"کپی کد تایید"** button inside the message bubble to copy the OTP code to your clipboard in one tap.
5. **Voice Reading Assistant:** Tap the speaker icon on any message bubble to hear it read aloud in Persian or English.
6. **Encrypted Backup:** Go to **Settings > Backup & Restore**, enter a master password, and tap **"ایجاد بکاپ"** to export an AES-256 encrypted archive.
