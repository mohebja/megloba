# Global SMS — User Manual & Operations Guide

**Project Name:** Global SMS (`com.global.sms`)  
**Target Audience:** End Users, Enterprise Users, Administrators  

---

## 1. Getting Started

1. **Setting as Default SMS Handler:**
   When launching Global SMS for the first time, tap **"Set as Default SMS App"** on the welcome screen to grant permission to send and receive messages.

2. **Selecting Your Interface Style:**
   Go to **Settings -> Appearance -> UI Style** to choose between:
   - **Classic SMS:** Clean, familiar messaging layout.
   - **Smart AI:** Displays the AI dashboard, OTP banners, and smart replies.
   - **Enterprise:** Dual-pane layout for large displays and power users.

---

## 2. Key Features Guide

### 2.1 Private Vault & Hidden Messages
- **Creating a Vault:** Navigate to **Settings -> Security -> Private Vault**. Set a 4-digit PIN or enable Fingerprint authentication.
- **Hiding Conversations:** Long-press any conversation thread on the main screen and tap **"Move to Private Vault"**.
- **Accessing Vault:** Tap the Lock icon on the top bar and authenticate with your PIN or Fingerprint.

### 2.2 Smart OTP Copy & Banking Insights
- **One-Tap Copy:** When a verification code arrives, tap **"Copy Code"** on the notification bar or banner.
- **Bank Statements:** View automatic summaries of deposits, withdrawals, and account balances categorized under the **Banking** tab.

### 2.3 Local Encrypted Backup & Restore
- **Backup:** Go to **Settings -> Backup -> Create Encrypted Backup**. Enter a master password to export a secure `.enc` archive.
- **Restore:** Tap **"Restore Backup"** and select your `.enc` file to restore your messages safely.
