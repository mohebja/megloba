# Global SMS — Release Notes v1.5.0-RELEASE

**Release Version:** 1.5.0-RELEASE  
**Release Date:** August 2, 2026  
**Build Target:** Production / Google Play Release  

---

## What's New in Version 1.5.0

### 🚀 On-Device AI & Intelligence System
- **Smart SMS Classification:** Automatically categorizes messages into Personal, OTP, Banking, Work, Shopping, Delivery, Advertisement, and Spam categories.
- **One-Tap OTP Copying:** Detects login verification codes with automatic service recognition (Digikala, Snapp, Banks, etc.) and provides instant notification copy buttons.
- **Banking Statements & Insights:** Parses banking transaction SMS messages and displays automatic summaries in Tomans and Rials.
- **Contextual Smart Replies:** Offers intelligent Persian and English quick responses with custom user reply configuration.

### 🛡️ Enterprise Security & Privacy
- **Private Vault & Biometric Auth:** Move sensitive conversations to a hidden vault guarded by PIN and Fingerprint/Face ID authentication.
- **AES-256 Encrypted Backups:** Local and cloud backups encrypted with hardware-backed KeyStore keys.
- **Screenshot Protection:** Screen recording and screenshot capture blocked on private views (`FLAG_SECURE`).
- **100% On-Device Privacy:** Zero message data transmitted off-device.

### 🎨 Design & Usability Polish
- **Material Design 3 Theme:** Dynamic Light, Dark, and Pure Black AMOLED modes.
- **Persian Vazirmatn Typography:** Native RTL layouts with custom font choices and pinch-to-zoom text scaling.
- **Dual SIM Support:** Dedicated SIM selection and delivery reporting for multi-SIM Android devices.
