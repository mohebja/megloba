# ♿ Global SMS - Accessibility Statement (بیانیه دسترس‌پذیری)

---

## 1. Compliance Standards
Global SMS is designed in full alignment with **Material Design 3 Accessibility Guidelines** and **Android Accessibility Standards (WCAG 2.1 AA)**.

## 2. Key Accessibility Implementation Features
- **Touch Targets:** All interactive icons, buttons, floating action buttons (FAB), and card elements enforce a minimum touch target size of **48dp x 48dp**.
- **Content Descriptions:** 100% of non-decorative icons and images feature descriptive localized `contentDescription` tags for TalkBack screen reader support.
- **Dynamic Font Scaling & Spacing:** All text labels utilize Scalable Pixels (`sp`), ensuring seamless scaling when system font sizes are increased.
- **Dynamic Color Contrast:** Built using Material 3 color schemes ensuring a high contrast ratio between foreground typography and background containers in both Light and Dark/AMOLED modes.
- **Right-To-Left (RTL) & Persian Support:** Native RTL layout mirroring and AutoMirrored directional iconography support for Persian and Arabic readers.
- **Text-to-Speech (TTS):** Integrated Text-to-Speech playback engine allowing visually impaired users to listen to SMS message contents.
