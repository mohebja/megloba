# Global SMS — Product Roadmap v2.0 & Future Evolution

**Project Name:** Global SMS (`com.global.sms`)  
**Target Horizon:** 2026 – 2027  

---

## 1. Overview & Vision

With Version 1.6.0 achieving zero-defect production certification, the v2.0 roadmap outlines next-generation capabilities, expanded ecosystem support, and enterprise commercial options.

---

## 2. Key Roadmap Pillars

### 2.1 Sprint 2.0: Next-Generation On-Device AI
- **Generative Reply Synthesis:** Fine-tuned local micro-LLM execution via Android Neural Networks API (NNAPI) / NPU acceleration.
- **Smart Attachment OCR:** Automated text extraction from images attached to MMS or received via chat.
- **Voice-to-Text Dictation:** Native Persian speech recognition for hands-free message composition.

### 2.2 Wear OS & Android Auto Companion Apps
- **Wear OS Tile & App:** Quick reply, voice input, and OTP notification copy directly on smartwatch.
- **Android Auto Integration:** Hands-free voice reading and voice response while driving.

### 2.3 Cross-Device Sync & Desktop Companion
- **End-to-End Encrypted Web Client:** Local Wi-Fi / WebRTC peer-to-peer sync between phone and browser without cloud servers.
- **Tablet / ChromeOS Dedicated Layouts:** Multi-window drag-and-drop attachment support.

### 2.4 Enterprise & Commercial (Pro) Features
- **Custom Rule Plugins:** Modular JavaScript / Kotlin script engine for custom automated SMS workflows.
- **Automated Business Auto-Responder:** Schedule vacation out-of-office SMS replies based on contact groups.
- **Hardware Token Integration:** FIDO2 / YubiKey physical key unlocking for Private Vault.
